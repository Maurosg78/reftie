# PRDs de Reftie

Carpeta reservada para PRDs a medida que el proyecto avance más allá
del spike de la Fase 0. Todavía no hay ninguno — no se generó una
plantilla `duxcare-prd-workflow` en este repo porque no está disponible
en este entorno; usarla como referencia de formato cuando corresponda
escribir el primer PRD real (probablemente en la Fase 2, modelo de
datos y segregación de rol, donde ya hay superficie de producto que
justifica un documento formal).

Hasta entonces, el documento de contexto (`reftie-brief-claude-code.md`,
fuera de este repo) y los ADRs en `docs/adr/` cumplen esa función.
